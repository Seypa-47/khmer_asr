# Earlier diagnostic experiments

These artifacts document the first Whisper and MMS experiments on the first 200 FLEURS test rows. Their training selections and filtering differed, so the scores are **not** the final controlled comparison. Use the matched results one directory above for the presentation headline.

`metrics_summary.json` and `summary_table.md` summarize the earlier runs. `whisper_test_predictions.json`, `whisper_warmup35_test_predictions.json`, `mms_test_metrics.json`, and the other files preserve their supporting outputs and figures. The reproducible early-run plotting script is `src/evaluate_and_plot.py`; its outputs are written here.
